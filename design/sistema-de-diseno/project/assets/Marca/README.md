# Marca

La gota oficial de DROPP, con los siete pétalos en los colores de la marca. No la redibujes, no la recolorees, no separes los pétalos. `gota.svg` es la versión en color (pantallas, etiqueta del pasaporte, story). `gota-contorno.svg` es la versión de una sola tinta, negra (#121212), para la impresora térmica, que no imprime color.

Cada pétalo es un oficio: amarillo Creación, verde Preparación y fermentación, cian Hielo y dilución, naranja Clásicos, rojo Sin alcohol, magenta Hospitalidad, violeta Coste y gestión.
