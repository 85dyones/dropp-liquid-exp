# ModoBalcao

El tema Barra: el mismo sistema en oscuro, para el turno de noche, cuando la pantalla clara deslumbra detrás de la barra.

- Se activa solo a la hora del turno de noche (la misma hora simulada del Turno) y se puede fijar. Es un tema de tokens (`data-theme="balcao"`), no otra pantalla: ningún componente cambia de dibujo.
- El papel pasa a carbón #171410 y la tinta a crema. Las tintas de sello y de texto de color se aclaran (`tinta-*`) para mantener el contraste.
- No cambian: los siete colores de la gota, la etiqueta térmica (papel físico) y el visor de la cámara.
- El grano sigue, más suave. Las sombras casi desaparecen en oscuro: el borde de tinta hace el trabajo.
