# Formula

El resultado de una cuenta en grande y, debajo, la fórmula que llegó a él.

- "La base de datos calcula, y cada cuenta enseña la fórmula debajo": ningún número de una cuenta aparece sin su fórmula.
- `.dp-resultado` con la etiqueta y el valor en display; `.dp-formula` en medida, una línea por paso (white-space: pre-line).
- Moneda: ES "13,83 €", PT "€13,83"; coma decimal en los dos.
