# Papel

La tarjeta de papel: fondo `cartao` con grano, borde de tinta de 1,5px y, cuando es una pieza de trabajo, marcas de corte en las esquinas.

- `.dp-papel` para toda tarjeta; `.dp-papel--corte` añade las dos marcas de corte (fuera de la tarjeta, a -8px, nunca sobre el texto).
- Dentro: `.dp-rot` solo cuando lleva código, fecha u hora (nunca como adorno encima de un título), el contenido y `.dp-nota`. Sin sombra: el papel es plano. Sombra solo en objetos físicos (etiqueta, vista previa).
