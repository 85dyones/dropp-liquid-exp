# Recado

El recado del Barback, el copiloto: hasta tres por turno, cada uno de un frente, con el porqué, la fuente y las salidas.

- Cabecera: el frente (Operación verde, Finanzas violeta, Marketing magenta) y el nivel de autonomía de ese frente (solo observa, sugiere, lo hace con un ok, lo hace solo).
- El título es la recomendación en una frase, con el número: "Extra de evento el sábado: cobra 180 €, no 120 €."
- Líneas de hechos (`.dp-linhas`), la fuente en `.dp-fonte` ("Tus registros de septiembre a noviembre") y de dos a tres opciones, la primera llena.
- La base de datos calcula, la IA explica: todo número del recado tiene que cuadrar con el Cuaderno.
