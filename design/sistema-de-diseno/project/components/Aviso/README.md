# Aviso

La confirmación de lo que acaba de pasar, en una franja de tinta encima de la navegación.

- Dice el hecho y el efecto: "El lote MEL-005 no estaba en la estación: dado de baja como merma, 0,2 L (1,22 €). Entra en el libro de turno."
- Cuando el prototipo simula algo del producto, el aviso dice "En la app, ...". Nunca afirma que se envió un mensaje si no se envió.
- Un aviso cada vez, con "Cerrar". Sombra `sombra-aviso`.
