# ReguaLote

El lote contado por el tiempo: primero "caduca el domingo", después la regla de hecho a caducidad con la marca de hoy.

- El tiempo va en display, en la tinta del estado: rojo caduca hoy o pronto, naranja se acaba hoy, violeta listo en días, verde activo.
- La regla se llena hasta hoy con la misma tinta; una marca de 2px señala hoy. Debajo, hecho y caducidad en medida; los datos técnicos (Brix, pH) van al final.
