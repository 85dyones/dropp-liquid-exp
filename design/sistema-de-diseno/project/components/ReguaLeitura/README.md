# ReguaLeitura

La regla que acompaña la lectura de una técnica: la medida del paso en grande, como un termómetro.

- Queda fija encima del texto. Muestra la medida del paso que está arriba en la lectura (10 L, −18 °C, 30 h, 10 min, 7 kg) y "paso 2 de 5".
- Los puntos ya leídos quedan llenos; el actual lleva `destaque`. Tocar una medida lleva hasta el paso.
