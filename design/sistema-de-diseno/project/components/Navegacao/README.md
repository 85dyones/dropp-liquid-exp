# Navegacao

La navegación de las cuatro áreas, fija al pie: Turno, Cuaderno, Pasaporte, Atlas.

- Siempre las cuatro, en el mismo orden. El área actual tiene `aria-current="page"` y tinta plena; las demás quedan en `tinta-suave`.
- Iconos de trazo (`assets/Icones`); el Pasaporte usa la gota en color.
- Altura `alvo-nav` (62px): es la zona táctil que más se usa con la mano mojada.
- En español, pasa `nomes` con Cuaderno y Pasaporte (esta versión ya los trae por defecto).
