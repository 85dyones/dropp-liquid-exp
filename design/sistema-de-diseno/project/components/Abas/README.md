# Abas

Pestañas de un área y la barra de volver de una pantalla de detalle.

- Cada área tiene como máximo tres pestañas (Lotes · Fichas · Cuentas; Estante · Archivo · Agenda). La activa lleva el subrayado `destaque` y la tinta plena.
- Las pantallas de detalle cambian las pestañas por `.dp-voltar-bar`: "← Volver" y el título en display con el código de catálogo ("Técnica · AT-022").
- Volver lleva a donde estaba la persona (comprobación, agenda), no siempre al inicio.
