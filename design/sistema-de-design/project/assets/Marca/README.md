# Marca

A gota oficial do DROPP, com as sete pétalas nas cores da marca. Não redesenhe, não recolora, não separe as pétalas da gota. `gota.svg` é a versão colorida (telas, rótulo, story). `gota-contorno.svg` é a versão de uma tinta só, preta (#121212), para a impressora térmica, que não imprime cor.

Cada pétala é um ofício: amarelo Criação, verde Preparo e fermentação, ciano Gelo e diluição, laranja Clássicos, vermelho Sem álcool, magenta Hospitalidade, violeta Custo e gestão.
