# Ícones

Traço de 1,8px numa grade de 24px, pontas e cantos arredondados, sem preenchimento. A tinta dos arquivos é #1C1A16 (token tinta no tema Papel); no app, o ícone usa a cor do texto ao lado. Turno é um relógio, Caderno uma folha com linhas, Atlas um livro aberto, Conferir a moldura de leitura de QR. O Passaporte usa a própria gota como ícone. Nunca emoji.
