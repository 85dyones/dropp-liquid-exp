# Recado

O recado do Barback, o copiloto: até três por turno, cada um de uma cadeira, com o porquê, a fonte e as saídas.

- Cabeçalho: a cadeira (Operação verde, Financeiro violeta, Marketing magenta) e o nível de autonomia daquela cadeira (só observa, sugere, faz com ok, faz sozinho).
- O título é a recomendação em uma frase, com o número: "Freela de evento no sábado: cobre €180, não €120."
- Linhas de fatos (`.dp-linhas`), a fonte em `.dp-fonte` ("Seus registros de setembro a novembro") e de duas a três opções, a primeira cheia.
- O banco calcula, a IA explica: todo número do recado tem de bater com o Caderno.
