# ModoBalcao

O tema Balcão: o mesmo sistema no escuro, para o turno da noite, quando a tela clara ofusca atrás do balcão.

- Liga sozinho na hora do turno da noite (a mesma hora simulada do Turno) e pode ser fixado. É um tema de tokens (`data-theme="balcao"`), não outra tela: nenhum componente muda de desenho.
- O papel vira carvão #171410 e a tinta vira creme. As tintas de carimbo e de texto colorido clareiam (`tinta-*`) para manter o contraste.
- Não mudam: as sete cores da gota, a etiqueta térmica (papel físico) e o visor da câmera.
- O grão continua, mais fraco. Sombras quase somem no escuro: a borda de tinta faz o trabalho.
