# Etiqueta

A etiqueta térmica de lote, 100 × 50 mm, só em preto, com QR que leva o texto do lote.

- Ordem fixa: a casa primeiro (o bar primeiro, o DROPP depois), nome do preparo, lote e recipiente, Feito e Vence (ou Revisar), ingredientes, ALÉRGENOS sempre, e no pé o QR, a instrução de leitura e "DROPP · Liquid Experience" com a gota em contorno.
- O QR é real (nível M, UTF-8) e guarda texto legível: "DROPP LOTE PF-001 / nome / Feito / Vence · temperatura / Alérgenos". Qualquer câmera lê, mesmo sem o app.
- Cores só `termico` e `termico-tinta`, nos dois temas: a etiqueta é papel físico.
