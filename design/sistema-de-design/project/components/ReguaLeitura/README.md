# ReguaLeitura

A régua que acompanha a leitura de uma técnica: a medida do passo em grande, como um termômetro.

- Fica fixa acima do texto. Mostra a medida do passo que está no topo da leitura (10 L, −18 °C, 30 h, 10 min, 7 kg) e "passo 2 de 5".
- Os pontos já lidos ficam cheios; o atual ganha `destaque`. Tocar numa medida leva até o passo.
