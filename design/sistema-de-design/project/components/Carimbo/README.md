# Carimbo

O carimbo do Passaporte: a prova de um marco, com tipo, título, linha e a tinta de quem assinou.

- Sete tipos, cada um com sua tinta e forma: Casa (violeta, redondo), Jornada (ciano, retângulo), Carta (laranja, oval), Escola (verde, retângulo), Arquivo (vermelho, redondo), Mentor (magenta, oval), Brinde (amarelo, retângulo).
- `.dp-carimbo--pendente` é tracejado: falta uma assinatura. Carimbo pendente não se compartilha.
- A tinta é a versão escura da cor da pétala (`tinta-*`), legível no papel; no Balcão vira a versão clara. O filtro `tinta-gasta` (feTurbulence, definido na página) dá a borda de borracha.
- Nunca nota, nunca número que compare pessoas. O carimbo bate uma vez (220 ms) e pode ser revisto com "Rever a tinta".
