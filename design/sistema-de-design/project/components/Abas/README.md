# Abas

Abas de uma área e a barra de voltar de uma tela de detalhe.

- Cada área tem no máximo três abas (Lotes · Fichas · Contas; Estante · Arquivo · Agenda). A ativa ganha o sublinhado `destaque` e a tinta cheia.
- Telas de detalhe trocam as abas por `.dp-voltar-bar`: "← Voltar" e o título em display com o código de catálogo ("Técnica · AT-022").
- O voltar leva para onde a pessoa estava (conferência, agenda), não sempre para o início.
