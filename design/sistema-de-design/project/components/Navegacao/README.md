# Navegacao

A navegação das quatro áreas, fixa no pé: Turno, Caderno, Passaporte, Atlas.

- Sempre as quatro, na mesma ordem. A área atual tem `aria-current="page"` e tinta cheia; as outras ficam em `tinta-suave`.
- Ícones de traço (`assets/Icones`); o Passaporte usa a gota colorida.
- Altura `alvo-nav` (62px): é o alvo mais usado com a mão molhada.
