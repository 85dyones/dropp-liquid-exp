# Papel

O cartão de papel: fundo `cartao` com grão, borda de tinta de 1.5px e, quando é peça de trabalho, marcas de corte nos cantos.

- `.dp-papel` para todo cartão; `.dp-papel--corte` acrescenta as duas marcas de corte (fora do cartão, a -8px, nunca sobre o texto).
- Dentro: `.dp-rot` só quando leva código, data ou hora (nunca como enfeite acima de título), conteúdo, `.dp-nota`. Sem sombra: o papel é chapado. Sombra só em objeto físico (etiqueta, prévia).
