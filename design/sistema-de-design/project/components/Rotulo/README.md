# Rotulo

O rótulo do Passaporte: a identidade do bartender no formato da etiqueta de preparo.

- No arco de tinta vai só a marca: a gota, "DROPP" e, embaixo, "Liquid Experience". O título "Passaporte do ofício" fica numa linha separada, fora do arco, entre fios.
- Depois: a gota com as pétalas no grau de cada ofício, o nome, o cargo e a casa, e as quatro medidas que se provam (anos, casas, fichas, formados). Cada número abre a prova.
- Fita "Meet · Share · Enjoy" e, no pé, o link público e "el bar primero".
